Additional compatibility information

Materials use the Built-in Standard shader. For URP, install Universal RP and run Tools > Japanese Aquarium > Convert Materials to URP once (tested with URP 14). Materials show as pink in URP until this step is done.

How it's made: the models are built by Python scripts in Blender, written with help from an AI coding assistant, and every model was checked by hand.
